# Faculty Feedback Automation

A simple React flow: students enter their name, roll number, branch, and semester, then rate each listed subject and faculty member.

Admins can edit the six sample subject and faculty assignments for each branch and semester. Roster edits are saved in the current browser and shown in the student feedback flow.

## Run locally

```sh
npm install
npm run dev
```

The default subject and faculty assignments are sample data. The admin login is a front-end demo and does not verify credentials. Roster edits are saved only in the current browser; feedback submissions are not saved or sent to a server.
